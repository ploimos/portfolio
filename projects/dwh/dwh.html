Data Warehouse

Un Data Warehouse (DWH) è un sistema di archiviazione centralizzato che integra dati da diverse fonti, ottimizzandoli per analisi e reporting.
Nel progetto ARDEO S.H. - FTRS, il DWH è progettato per tracciare transazioni e le relativi frodi in funzione dell'orario, del Paese, del provider mail o della carta.
Sfrutterò l'alternativa gratuita di PostgreSQL la sua relativa Shell SQL (psql) per scrivere queries che ci permettano di trovare dati significativi e correlazioni utili per il caso di studio.

Collegamento e popolamento DB

1. Creazione Database

CREATE DATABASE ardeo_finretail
    WITH 
    OWNER = postgres
    ENCODING = 'UTF8'
    CONNECTION LIMIT = -1;

Creazione del database principale con encoding UTF-8 per supportare caratteri speciali.

2. Connessione al Database

\c ardeo_finretail

Comando per connettersi al database appena creato tramite terminale PSQL.

3. Creazione Tabelle Dimensioni (DIM)

-- Tabella Paesi
CREATE TABLE dim_country (
    country_id SERIAL PRIMARY KEY,
    country_name VARCHAR(100) NOT NULL,
    gmt_offset NUMERIC(3,1),
    zone VARCHAR(50)
);

-- Tabella Prodotti
CREATE TABLE dim_product (
    product_id CHAR(1) PRIMARY KEY,
    product_name VARCHAR(50) NOT NULL
);

-- Tabella Provider Email
CREATE TABLE dim_email_provider (
    provider_id SERIAL PRIMARY KEY,
    provider_name VARCHAR(50) NOT NULL
);

-- Tabella Tipi Carta
CREATE TABLE dim_card_type (
    card_type_id SERIAL PRIMARY KEY,
    type_name VARCHAR(20) NOT NULL
);

-- Tabella Marchi Carta
CREATE TABLE dim_card_brand (
    brand_id SERIAL PRIMARY KEY,
    brand_name VARCHAR(50) NOT NULL
);

Creazione delle tabelle dimensioni che contengono i parametri statici del sistema.

4. Popolamento Tabelle DIM

-- Inserimento paesi (esempio)
INSERT INTO dim_country (country_name, gmt_offset, zone) VALUES
('Italy', 1.0, 'Europe West'),
('United States', -5.0, 'North America');

-- Inserimento prodotti (esempio)
INSERT INTO dim_product (product_id, product_name) VALUES

-- Inserimento provider email (esempio)
INSERT INTO dim_email_provider (provider_name) VALUES
('gmail.com'),

Inserimento dei dati parametrici nelle tabelle dimensioni.

5. Creazione Tabella Fatti (FACT)

CREATE TABLE fact_transactions (
    transaction_id BIGSERIAL PRIMARY KEY,
    transaction_date TIMESTAMP NOT NULL,
    amount NUMERIC(10,2) NOT NULL,
    is_fraud BOOLEAN NOT NULL,
    product_id CHAR(1) REFERENCES dim_products(product_id),
    country_id INTEGER REFERENCES dim_country(country_id),
    provider_id INTEGER REFERENCES dim_email_providers(provider_id),
    card_type_id INTEGER REFERENCES dim_card_types(card_type_id),
    card_brand_id INTEGER REFERENCES dim_card_brands(brand_id)
);

Creazione della tabella fatti con i vincoli di chiave esterna.

6. Creazione Tabella Temporanea

CREATE TEMPORARY TABLE temp_transactions (
    transaction_id BIGINT,
    transaction_date TIMESTAMP,
    amount NUMERIC(10,2),
    is_fraud BOOLEAN,
    product_id CHAR(1),
    country_name VARCHAR(100),
    email_provider VARCHAR(50),
    card_type VARCHAR(20),
    card_brand VARCHAR(50)
);

Tabella temporanea per il caricamento iniziale dei dati dal CSV.

7. Caricamento Dati da CSV

\COPY temp_transactions FROM '/percorso/del/tuo/file.csv' DELIMITER ',' CSV HEADER;

Importazione dei dati dal file CSV nella tabella temporanea.

8. Trasferimento Dati alla Tabella Fatti

INSERT INTO fact_transactions (
    transaction_date,
    amount,
    is_fraud,
    product_id,
    country_id,
    provider_id,
    card_type_id,
    card_brand_id
)
SELECT 
    t.transaction_date,
    t.amount,
    t.is_fraud,
    t.product_id,
    c.country_id,
    e.provider_id,
    ct.card_type_id,
    cb.brand_id
FROM temp_transactions t
JOIN dim_country c ON t.country_name = c.country_name
JOIN dim_email_provider e ON t.email_provider = e.provider_name
JOIN dim_card_type ct ON t.card_type = ct.type_name
JOIN dim_card_brand cb ON t.card_brand = cb.brand_name;

Migrazione dei dati dalla tabella temporanea alla tabella fatti con i riferimenti corretti.

9. Verifica Finale

SELECT 
    (SELECT COUNT(*) FROM temp_transactions) AS temp_count,
    (SELECT COUNT(*) FROM fact_transactions) AS fact_count,
    (SELECT COUNT(*) FROM temp_transactions) - 
    (SELECT COUNT(*) FROM fact_transactions) AS difference;

Controllo che tutti i record siano stati migrati correttamente.

10. Pulizia

DROP TABLE temp_transactions;

Eliminazione della tabella temporanea dopo il trasferimento dei dati.

1. Panoramica Generale Frodi

SELECT 
    COUNT(*) AS "Transazioni totali",
    (SELECT COUNT(*) FROM fact_transactions WHERE is_fraud) AS "Numero di frodi",
    ROUND(100.0 * (SELECT COUNT(*) FROM fact_transactions WHERE is_fraud) / COUNT(*), 2) AS "Percentuale di frodi",
    MIN(amount) AS "Importo minimo (frode)",
    MAX(amount) AS "Importo massimo (frode)",
    ROUND(AVG(amount), 2) AS "Importo medio (frode)"
FROM fact_transactions;

10. Rilevamento Transazioni Anomale

SELECT 
    transaction_id AS "ID transazione",
    amount AS "Importo frode",
    transaction_date AS "Data transazione",
    c.country_name AS "Paese",
    p.product_name AS "Prodotto"
FROM fact_transactions f
JOIN dim_country c ON f.country_id = c.country_id
JOIN dim_product p ON f.product_id = p.product_id
WHERE 
    is_fraud AND
    amount > (SELECT AVG(amount) + 3 * STDDEV(amount) FROM fact_transactions WHERE is_fraud)
ORDER BY "Importo frode" DESC;

11. Efficacia Sistema Antifrode

SELECT 
    (SELECT COUNT(*) FROM fact_transactions WHERE is_fraud) AS "Numero frodi",
    (SELECT COUNT(*) FROM fact_transactions WHERE NOT is_fraud) AS "Transazioni legittime",
    ROUND(100.0 * (SELECT COUNT(*) FROM fact_transactions WHERE is_fraud) / 
          (SELECT COUNT(*) FROM fact_transactions), 2) AS "Tasso frode";

12. Top 5 Paesi per Frodi

SELECT
    c.country_name AS "Paese",
    COUNT(*) AS "Transazioni totali",
    SUM(CASE WHEN t.is_fraud THEN 1 ELSE 0 END) AS "Frodi",
    ROUND(AVG(t.amount), 2) AS "Importo medio frode",
    ROUND(100.0 * AVG(is_fraud::int), 2) AS "Percentuale frodi"

JOIN dim_country c ON t.country_id = c.country_id

ORDER BY "Frodi" DESC
