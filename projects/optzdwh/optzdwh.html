Ottimizzazione del Data Warehouse

Il Data Warehouse di ARDEO S.H. - FTRS è progettato per garantire prestazioni elevate e integrazione fluida con i sistemi ETL, ML e Reporting. Ecco le strategie chiave implementate:

Strategie di Indicizzazione

  • Indici columnstore per query analitiche su tabelle fattuali (fact_transactions)
  • Indici ottimizzati sui campi temporali (TransactionDate) e chiavi di join
  • Partizionamento mensile dei dati storici per ridurre i tempi di scansione

Modello Star-Schema

Struttura ottimizzata per analisi:

  • Tabelle fattuali: fact_transactions (400+ milioni di righe)
  • Tabelle dimensionali: dim_users, dim_products, dim_geography
  • Viste materializzate per accelerare i report Power BI

Performance Monitoring

Strumenti implementati:

  • Query Store per tracciare le query più lente
  • Alert automatici su utilizzo CPU/disco anomalo
  • Ottimizzazione automatica degli indici tramite Azure SQL Advisor

Integrazione con il Sistema ML

Flusso dati ottimizzato:

  • Batch notturni: Aggiornamento tabelle alle 2:00 CET
  • Viste dedicate (v_ml_training_data) per l'alimentazione del modello
  • Trigger in tempo reale per transazioni ad alto rischio
