Ottimizzazione DWH

In ambiente enterprise si implementerebbe:

  • Indici Columnstore: Per query analitiche su grandi volumi (Azure SQL Data Warehouse)
  • Partizionamento: Per mese/anno su fact_transactions con filegroup multipli
  • Materialized Views: Pre-aggregazioni per le dashboard (con refresh incrementale)
  • Intelligent Query Processing: Adaptive joins e batch mode su Azure SQL Hyperscale

Nella pratica, ottimizzerò lo schema con indici B-tree standard e viste materializzate manuali su PostgreSQL.
